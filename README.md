# slb350/homebrew-tap

Homebrew formulae for [slb350](https://github.com/slb350)'s tools.

```sh
brew install slb350/tap/drep
```

| Formula | What it is |
|---|---|
| `drep` | A local commit gate: runs the linters your repository configures, and sends changed code to an LLM for review. [Source](https://github.com/slb350/drep) |

Everything in `Formula/` is generated by [cargo-dist](https://opensource.axo.dev/cargo-dist/) and pushed here by each project's release workflow. Edit the project, not the formula.
